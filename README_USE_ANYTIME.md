CHANDAMAMA PHASE-2 PLOT MAP — REUSE GUIDE
==========================================

A. Reuse this exact Chandamama map
----------------------------------
1. Download and save chandamama_phase2_interactive_v5.html on your computer.
2. Keep a backup copy in Google Drive / OneDrive / an external drive.
3. Double-click the HTML file and open it in Chrome or Microsoft Edge.
4. Update plot statuses and details in the map.
5. Export/backup plot data regularly if the map offers an export option. Do not rely on browser storage as your only copy.

Important: this HTML contains the Chandamama Phase-2 geometry. It is NOT a blank, universal DXF importer. Do not replace geometry or plot data by hand unless the new layout has been processed and verified.

B. Process a different DXF layout
---------------------------------
1. Start a new ChatGPT conversation and attach the original DXF. Also attach the PDF/site-plan image if available, because it helps verify plot labels and boundaries.
2. Paste the reusable prompt from REUSABLE_DXF_PROMPT.txt.
3. Review the generated boundary overlay and the uncertain-label report before using it for sales.
4. Confirm plot numbering, drawing units, and candidate boundaries; only then begin entering buyer and payment data.
5. Keep a separate map and separate data backup for each project/layout.

C. Multi-staff warning
----------------------
This local HTML version is not a shared cloud database. Different staff members using separate copies/browsers will not automatically see one another's edits. For shared real-time use, the map needs to be rebuilt/connected to a hosted backend with user accounts, permissions, backups, and an audit trail.

D. Accuracy warning
-------------------
A polygon that is mathematically closed/valid is not automatically a real plot. Do not make sale/allotment decisions until the map is compared against the approved plan and ambiguous plot IDs/boundaries are resolved.
